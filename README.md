# ClipToGif

スマートフォンの画面録画や動画ファイルから、必要な部分だけを切り出して軽量GIFアニメーションへ変換するWebツールです。動画データを外部サーバーへアップロードせず、ブラウザ内のみで処理します。

## こんなときに
- スマホの画面録画や操作手順を、チャット（Slack / Discordなど）で手軽に共有したいとき
- ブログやドキュメントに、短い操作デモGIFを埋め込みたいとき
- 動画編集ソフトを使わずに、ブラウザだけで素早くGIFを作成したいとき

## 主な機能
- **ブラウザ内ローカル処理**: 動画データを外部サーバーへアップロードせず、ブラウザ内で完結して処理します。
- **区間指定と微調整**: 開始位置・終了位置のスライダーに加え、「現在の再生位置を設定」ボタンや±0.1秒の微調整ボタンで直感的に切り出し範囲を指定できます（最大10秒）。
- **長辺基準の最適化リサイズ**: 縦動画・横動画を問わず、長辺基準（320px / 480px / 640px）でアスペクト比を維持したまま均一なサイズへ自動調整します。
- **軽量化設定**: 10fps / 15fps の選択により、ファイルサイズを抑えた軽量GIFを出力できます。
- **バックグラウンド処理**: Web Workerを活用して変換処理を行うため、処理中も画面がフリーズしません。
- **即時プレビュー＆容量確認**: 生成されたGIFをその場で確認し、推定容量ゾーン（軽量・標準・注意）を確認してダウンロードできます。

## 使い方

### ブラウザで使う（かんたん）
1. [ClipToGif を開く](https://zero-dev.jp/cliptogif/) にアクセスします。
2. 「動画を選択」を押して動画を選ぶか、または「✨ サンプル動画で試す」を押します。
3. プレビュー画面で、開始スライダーと終了スライダーを動かして変換したい範囲（最長10秒）を合わせます。
4. 必要なら、出力サイズ（「チャット用 320px」「ブログ用 480px」「高画質 640px」）やフレームレート（「10 fps」「15 fps」）を選びます。
5. 「GIFアニメーションを生成」を押します。
6. 「GIF生成完了」画面に結果が表示されたら、「GIFをダウンロード」を押して保存します。

### ダウンロードして使う（パソコンに保存する場合）
1. 本リポジトリのファイルをダウンロード（またはクローン）します。
2. Windows環境では、フォルダ内の `ツール起動.bat` をダブルクリックして起動します（自動的にローカルサーバーが立ち上がりブラウザが開きます）。

## うまくいかないとき
- iPhoneの画面録画でエラーが出る場合: iPhoneの「設定」→「カメラ」→「フォーマット」が「高効率（HEVC）」になっている場合があります。「互換性優先（H.264）」で撮影された動画をお使いいただくか、MP4形式に変換してからお試しください。
- 変換が途中で失敗する場合: 動画の長さが10秒を超えているか、高解像度のまま長時間の変換を行っている可能性があります。範囲を短く（3〜5秒程度）設定してお試しください。

## 動作環境
- Google Chrome（推奨）
- Microsoft Edge
- Mozilla Firefox
- Apple Safari（iOS / macOS）
※HTML5 Video、Canvas、Web Worker、Blob URLに対応した一般的なモダンブラウザが必要です。

## 制限・注意
- 変換可能な区間の長さは最大10秒（下限0.5秒）です。
- 動画の再生可否および変換可否は、お使いのブラウザがサポートするコーデックに依存します。
- GIFは色数制限（最大256色）があるため、グラデーションや実写映像では粗さやディザリングが生じる場合があります。

## 外部通信
- 動画データ・画像データの外部送信は一切行いません（ブラウザ内ローカル処理）。
- 画面表示用のフォント読み込みのため、Google Fonts（`fonts.googleapis.com`, `fonts.gstatic.com`）への通信のみ発生します。

### ローカル実行方法
本ツールは Web Worker および ES Modules を使用しているため、ローカルで動かすにはローカルWebサーバーが必要です。
`ツール起動.bat` を実行するか、または任意の静的サーバー（例: `python -m http.server 8000`）を起動してアクセスしてください。
